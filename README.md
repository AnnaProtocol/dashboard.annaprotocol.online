# ANNΛ Protocol — Dashboard deployment

This repository contains the **compiled, static frontend deployment** of the ANNA Protocol dashboard, published through GitHub Pages.

**Live dashboard:** https://dashboard.annaprotocol.online

## What is included

| Path | Description |
| --- | --- |
| `index.html` | Entry point for the built application |
| `assets/` | Bundled JavaScript, CSS, and images produced by Vite |
| `AnnaAttestation_abi.json` | Attestation contract ABI |
| `AnnaIdentity_abi.json` | Identity contract ABI |
| `AnnaReputation_abi.json` | Reputation contract ABI |
| `CNAME` | GitHub Pages custom-domain mapping |
| `_headers` | Header configuration file; **GitHub Pages does not natively apply Netlify-style `_headers` rules** |
| `vite.svg` | Default Vite asset retained in the deployment |

## Source versus deployment

**This is not the complete React source tree.** It contains output generated by a Vite build. Source files such as `src/App.jsx`, `src/components/`, and `package.json` belong to the separate development project and are not present here.

The ABI JSON files are intended to be public client-side contract interfaces. They do not replace the Solidity source, audits, or the backend/verifier service.

## Deployment workflow

1. Make changes in the **development** project (React/Vite), not in generated JavaScript bundles.
2. Run `npm install` as needed, then `npm run build`.
3. Copy the **contents** of `dist/` to this deployment repository, retaining `.git/` and `CNAME`.
4. Check asset paths and ABI requests against the deployed domain.
5. Commit and push the updated build to the configured GitHub Pages branch.
6. Verify the live site, including wallet connection, network selection, contract reads, and browser console errors.

Do not commit development `.env` files or private credentials. Any `VITE_*` value included in a frontend bundle is publicly readable.

## Limitations

This deployment does not host the Python backend or a 24/7 verifier. The dashboard's blockchain reads depend on RPC availability and correctly configured contracts. The current public demonstration is associated with Polygon Amoy testnet.
